# xxt自动答题助手

Chrome 扩展（v0.1.0，需 Chrome 111+，零构建加载即用）。
在答题页自动完成：读取题目 → 判断题型 → 调用 AI → 回填答案。

AI 用你自己的（任意 OpenAI 兼容端点），扩展不代付、不经过第三方服务器。调用一次30题为例子 0.01（deepseek 未命中）

**支持**：单选/多选、填空、文本匹配；题目在同源 iframe 内也能读到。
**不支持**：排序、下拉、写作、思考题、词库完形、错题订正；跨域 iframe 内的题目读不到。

---

## 安装

1. `chrome://extensions` → 打开**开发者模式**
2. **加载已解压的扩展程序** → 选含 `manifest.json` 的那层目录
3. 图标没显示？点拼图块 🧩 → 在「自动答题助手」右侧点图钉 📌

改完代码回到扩展页点刷新 ⟳ 即可生效，无需构建。

## 配置

点工具栏图标，填三项后点**「测试连接」**，显示"连接正常"再点**「保存配置」**：

- **API 端点**：写到 `/v1` 结尾，如 `https://api.deepseek.com/v1`（扩展自动拼 `/chat/completions`）
- **API Key**：本地 Ollama 可留空
- **模型**：如 `deepseek-chat`

其他端点：OpenAI `https://api.openai.com/v1` · Ollama `http://localhost:11434/v1`

三个勾选框勾上即存。更多设置项在弹窗底部「打开完整设置 →」。
**「自动提交」默认关闭**，建议先人工确认答案质量。

## 使用

1. 打开答题页，右下角出现悬浮面板（`已启用，待命中`）
2. 点**「开始答题」**，日志区会实时显示每一步
3. 点**「停止」**可随时中止

| 按钮            | 作用                            |
| --------------- | ------------------------------- |
| 开始答题 / 停止 | 启停                            |
| 诊断            | 勘察页面结构，报告写入日志区    |
| 复制            | 复制日志全文（提 issue 时附上） |

控制台可用 `__AA_DEBUG__.extract() / pick() / runOnce() / stop() / cfg`。

## 出问题怎么办

**点面板「诊断」→ 再点「复制」**，对照报告定位：

| 报告显示                      | 处理                       |
| ----------------------------- | -------------------------- |
| 题目容器未命中                | 不是答题页，或页面没加载完 |
| `iframe#x → 跨域，脚本读不了` | 无法解决（浏览器安全策略） |
| 选项元素 0 个 / 提取失败      | 附诊断报告提 issue         |
| `匹配题型: 无`                | 该题型尚未支持             |

再看日志区最后几行，主循环退出原因都会写明
（`未找到答题面板` / `未匹配到题型` / `没找到「下一题」按钮` / `全部完成`）。

诊断报告中的 `url`、`baseUrl`、`apiKey` **已自动脱敏**，可直接附在 issue 里。

**已知限制**：旧版作业页（`questionLi` 结构）回填依赖页面全局函数，
扩展运行在隔离环境中无法直调，现改用模拟点击兜底，**成功率不稳定**；
站点改版会导致选择器失效，选择器集中在 `src/content/dom/selectors.js`。

## 隐私

只有一个出网请求：`POST {你填的 baseUrl}/chat/completions`，仅发题干和选项。
无埋点、无统计、不读 cookie。API Key 存 `chrome.storage.local`，源码不含任何凭据。

**卸载**：`chrome://extensions` 移除卡片。清 Key 另需删除
`%LOCALAPPDATA%\Google\Chrome\User Data\<Profile>\Local Extension Settings\<扩展ID>\`。
